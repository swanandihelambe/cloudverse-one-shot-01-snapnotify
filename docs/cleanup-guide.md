# SnapNotify Cleanup Guide

## Overview

This document provides step-by-step instructions for safely removing all AWS resources created during the deployment of the **SnapNotify** project.

Following this guide ensures that no unnecessary AWS resources remain active after the project is completed, helping avoid unexpected charges and maintaining a clean AWS environment.

---

## Resources Created

The SnapNotify project provisions the following AWS resources:

- Amazon S3 Bucket
- AWS Lambda Function
- IAM Execution Role
- Amazon SNS Topic
- Amazon SNS Subscription
- Amazon CloudWatch Log Group (created automatically)

---

## Cleanup Sequence

Resources should be deleted in the following order:

1. Remove the Amazon S3 Trigger
2. Delete the AWS Lambda Function
3. Delete the IAM Execution Role
4. Delete the Amazon SNS Subscription
5. Delete the Amazon SNS Topic
6. Empty the Amazon S3 Bucket
7. Delete the Amazon S3 Bucket
8. Delete the Amazon CloudWatch Log Group (Optional)

---

# Step 1 – Remove the Amazon S3 Trigger

## Objective

Remove the event notification that invokes the Lambda function whenever a new object is uploaded.

## Procedure

1. Open the AWS Lambda Console.
2. Select the **snapnotify-lambda** function.
3. Locate the Amazon S3 trigger in the Function Overview section.
4. Delete the trigger.

## Verification

Confirm that no S3 trigger is associated with the Lambda function.

---

# Step 2 – Delete the AWS Lambda Function

## Objective

Remove the Lambda function responsible for processing S3 upload events.

## Procedure

1. Open the AWS Lambda Console.
2. Select **snapnotify-lambda**.
3. Choose **Actions → Delete Function**.
4. Confirm the deletion.

## Verification

Verify that the Lambda function no longer appears in the Lambda dashboard.

---

# Step 3 – Delete the IAM Execution Role

## Objective

Remove the IAM execution role that granted permissions to the Lambda function.

## Procedure

1. Open the IAM Console.
2. Navigate to **Roles**.
3. Locate the execution role created for SnapNotify.
4. Delete the role.

## Verification

Verify that the IAM role no longer exists.

---

# Step 4 – Delete the Amazon SNS Subscription

## Objective

Remove the email subscription associated with the SNS topic.

## Procedure

1. Open the Amazon SNS Console.
2. Navigate to **Subscriptions**.
3. Select the subscription.
4. Click **Delete**.
5. Confirm the deletion.

## Verification

Verify that the subscription is removed.

---

# Step 5 – Delete the Amazon SNS Topic

## Objective

Remove the SNS topic created for SnapNotify.

## Procedure

1. Open the Amazon SNS Console.
2. Navigate to **Topics**.
3. Select the SnapNotify topic.
4. Click **Delete**.
5. Confirm the deletion.

## Verification

Verify that the SNS topic no longer appears in the Topics list.

---

# Step 6 – Empty the Amazon S3 Bucket

## Objective

Delete all objects stored within the S3 bucket.

## Procedure

1. Open the Amazon S3 Console.
2. Select the SnapNotify bucket.
3. Select all objects.
4. Click **Delete**.
5. Confirm the deletion.

## Verification

Verify that the bucket contains no objects.

---

# Step 7 – Delete the Amazon S3 Bucket

## Objective

Delete the bucket after all objects have been removed.

## Procedure

1. Return to the S3 Buckets page.
2. Select the SnapNotify bucket.
3. Click **Delete**.
4. Enter the bucket name for confirmation.
5. Click **Delete bucket**.

## Verification

Verify that the bucket is no longer listed in Amazon S3.

---

# Step 8 – Delete the Amazon CloudWatch Log Group (Optional)

## Objective

Remove CloudWatch logs generated by the Lambda function.

## Procedure

1. Open the Amazon CloudWatch Console.
2. Navigate to **Log Groups**.
3. Locate the log group associated with the Lambda function.
4. Delete the log group.

## Verification

Verify that the log group no longer appears in CloudWatch.

# Cost Considerations

The SnapNotify project is designed to operate within the AWS Free Tier.

Deleting all resources after testing ensures that no unnecessary AWS charges are incurred.

---

# Conclusion

Following this cleanup guide completely removes all AWS resources associated with the SnapNotify project and restores the AWS environment to its original state.
